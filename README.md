# pwnstore_application
This is groundwork for what will become an interactive teaching machine! With integrated AI grading, this teaching application aims to serve as a proof of concept for the use of a locally hosted AI. The AI is installed on the user's PC and, without the need for API keys or an LLM, can help the user answer questions, acting as a 24/7 tutor. The legal and ethical use disclaimer is at the bottom of this README.md file; before downloading this application, ensure you familiarise yourself with the legal and ethical use disclaimer.
